# 🚀 Job Portal with Admin Dashboard
A full-stack **Job Portal Web Application** featuring a powerful **Admin Moderation System** to manage users, recruiters, job approvals, and reports — designed with real-world platform logic similar to LinkedIn & Indeed.

---

## 🛠 Tech Stack
- **Frontend:** React.js, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Tools:** Git, GitHub, Postman  

---

## 🎯 Features

### 👤 Users
- Job seeker registration & login  
- Browse and apply for jobs  
### 🏢 Recruiters
- Recruiter registration  
- Post job listings  
- Jobs remain **Pending** until admin approval  
### 🛡 Admin Dashboard
- View all users  
- Block / Unblock users  
- Approve or reject recruiters  
- Approve or reject job posts  
- Handle reports/complaints  
- View system analytics  

---

## 🔄 Approval Workflow
- Recruiters → Pending → Admin approval → Active  
- Jobs → Pending → Admin approval → Live
